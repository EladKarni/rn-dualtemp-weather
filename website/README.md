# website

A Next.js site scaffolded with [create-estack-app](https://github.com/your-org/create-estack-app).

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [DaisyUI](https://daisyui.com/)
- [Roboto (humanist)](https://fonts.google.com/) (via next/font)

## Configuration

- **Theme:** dark
- **Header:** default
- **Font:** Roboto (humanist)

## Sections

- Hero
- Features
- Contact

## Getting Started

```bash
cd website
yarn install
yarn dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `yarn dev` | Start development server |
| `yarn build` | Build for production |
| `yarn lint` | Run ESLint |
| `yarn test` | Run tests |
